A two-part micro-confession for the [Unsent: The Micro-Confession Sprint](https://make.fun/bounty/u-boothlord-unsent-the-micro-confession-sprint-8c6596ba) bounty on make.fun: a `To:` line naming who the unsent message was meant for, and the unsent line itself, written exactly as it was typed, with no explanation after it.

`main.py` writes the confession to `/output/entry.txt` (UTF-8, 116 characters, two lines) and self-checks the gate before writing: 1–260 characters total, message line at most 200 characters. The program is deterministic — repeated runs produce byte-identical output.

## Run

```sh
python3 main.py
```
